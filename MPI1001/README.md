# MPI1001

It's a touch display made with Raspberry Pis in mind.
This display can be found under brands such as Waveshare and Lafvin.

# Some notes

To export this project as a STEP file, you **MUST** enable the following option(s):

```
Export single object placement
```

To import it properly in other projects, you **MUST** have **ONLY** the following option(s) enabled:

```
Enable STEP compound merge
```

> [!CAUTION]
> If you don't set STEP import/export as explicitly mentioned, the model will likely be imported with misplaced parts or missing faces.
