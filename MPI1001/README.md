# MPI1001

It's a touch display made with Raspberry Pis in mind.
This display can be found under brands such as Waveshare and Lafvin.

> [!NOTE]
> As of 2026/09/26: I removed imported components from the project as they'd cause issues regarding exporting the project as a STEP (and therefore importing the STEP file). I left two project files, one with only the tablet screen and another one with all the ports added.
